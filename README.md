# Notion Export to CSV - Chrome Extension

Extensión de navegador desarrollada de forma 100% independiente para solucionar la necesidad real de exportar datos limpios y estructurados desde bases de datos y tablas de Notion a archivos CSV.

---

## 🚀 Características Principales

* **Exportación Directa:** Convierte tablas y bloques de datos de Notion en archivos CSV listos para usar en un solo clic.
* **Arquitectura Moderna:** Construida bajo las especificaciones técnicas de **Manifest V3** de Google Chrome.
* **Ejecución Ligera:** Script optimizado que opera en segundo plano (*Content Scripts*) sin afectar el rendimiento del navegador.
* **Sin Dependencias Pesadas:** Desarrollado con JavaScript puro (ES6+), HTML5, CSS3 y las APIs nativas de Chrome.

---

## 🛠️ Stack Tecnológico y Arquitectura

* **Manifest V3:** Cumplimiento con los estándares de seguridad y privacidad actuales de Chrome Web Store.
* **Content Scripts:** Inyección de lógica limpia para lectura y manipulación del DOM de Notion.
* **Popup UI:** Interfaz minimalista para control directo por parte del usuario.
* **Tecnologías:** JavaScript (ES6+), Chrome Extension APIs, DOM Manipulation, JSON, CSS3, HTML5.

---

## 💻 Instalación Local (Modo Desarrollador)

1. Clona o descarga este repositorio en tu equipo local.
2. Abre Google Chrome y navega a `chrome://extensions/`.
3. Activa el **Modo de desarrollador** en la esquina superior derecha.
4. Haz clic en **Cargar descomprimida** (*Load unpacked*) y selecciona la carpeta de este proyecto.
